# vq-12 — accessibility (M9.T01–T03; R-223, NFR-A1…A6)

Runs on the dev-signed build with computer use (Q-021) and, for the VoiceOver part, the owner's grants listed in
`docs/prd/M9-owner-steps.md`. Captures with `tools/visual/cap.sh`, recordings with `tools/rec.sh`.

## Automated legs first (no grants)
1. `tools/at/at-223-probe.sh` → `build/at/AT-223/<lang>/{probe,inventory}.json` (0 failures; evil title announced).
2. `make test-unit FILTER=StreamAnnouncerTests,DesignTokenContrastTests,LaunchOverrideTests,CopyPipelineTests`.
3. `python3 -I tools/ci/a11y-lint.py`, `python3 -I tools/l10n/l10n-check.py --langs de,fr,es,nl,pt --require translated`.

## §Keyboard (AT-223 part 1)
Full Keyboard Access on (`defaults write -g AppleKeyboardUIMode -int 2`; restore with `defaults delete -g AppleKeyboardUIMode`).
Tab through S-05, S-08, S-21 (each of the 13 sections), S-18 palette, S-22 shortcut list → `focus-<screen>`; every
focused control shows `focus.ring`. Then `xcodebuild test … -only-testing:AntiChatUITests/KeyboardOnlyTests`.

## §System settings (AT-223 part 2)
- Reduce Motion on (System Settings → Accessibility → Display) → stream a reply, record 5 s (`tools/rec.sh`),
  `python3 -I tools/frametime.py rm-stream.mov --crop <message region> --fade-detect` → `fade frames: 0`.
- Reduce Transparency on → S-01, S-05, S-21 → `rt-<screen>`.
- Increase Contrast on → S-05, S-08, S-06 (Evil) → `ic-<screen>`.
- Text size 24 pt (Settings → Appearance stepper max) → S-05, S-08, S-21 Privacy & Data, S-20 → `ts24-<screen>`.
- Contrast samples: `python3 -I tools/visual/contrast-sampler.py build/visual/<ver>/vq-01/*.png --points 64 --min 4.5 --large-min 3.0`.
Bars: no screen below its rubric bar; A ≥ 4 on ★ screens.

## §Audit (AT-223 part 3, NFR-A6)

   `tools/a11y/audit-ignores.yml` needs lead sign-off per entry).

## §VoiceOver walkthroughs (NFR-A6)
For each journey 1–16: ⌘F5 (dismiss the welcome dialog with [Use VoiceOver] the first time), caption panel on,
perform the journey with VO keys only (VO = ⌃⌥; VO-→, VO-Space, VO-⇧-↓), record in
`build/visual/<ver>/vq-12-a11y/vo-journey-<n>.md` from `tools/a11y/vo-walkthrough.md`. Check per journey:
- every control is announced with its label and role (no "button" alone, no symbol names);
- an Evil chat's window is announced with "Evil mode chat"; an incognito one with "Incognito chat";
- a streamed reply is announced once when done (or sentence by sentence when Settings → General → "VoiceOver reads
  replies" = Sentence by sentence), never per token, never the reasoning;
- sheets put focus on their first field and return it to the invoking control when closed.
Verdict PASS/FAIL; a FAIL is allowed only on non-★ journeys with an S2 bug linked.
