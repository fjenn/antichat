If `/Applications/Microsoft {Excel,Word,PowerPoint}.app` are absent, the build agent may not buy or sign in to Microsoft 365 (spending money, PLAN §1.8), and installing the free view-only apps needs an admin password or Apple ID. Accept either id per app: Numbers `com.apple.Numbers` | `com.apple.iWork.Numbers`; Pages `com.apple.Pages` | `com.apple.iWork.Pages`; Keynote `com.apple.Keynote` | `com.apple.iWork.Keynote`; Preview `com.apple.Preview`; TextEdit `com.apple.TextEdit`; Word `com.microsoft.Word`; Excel `com.microsoft.Excel`; PowerPoint `com.microsoft.Powerpoint`.
