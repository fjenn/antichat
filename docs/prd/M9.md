Polite = never interrupts the user's VoiceOver focus reading (`.low`/queued). Reasoning text is never announced; tool/memory ActivityLines announce their one-line summary once.
4. **Keyboard (R-223 AC2, NFR-A3):** `tools/a11y/keyboard-paths.yml` lists every function (≈ 120 entries: menus, sidebar, composer actions, message actions, versions, artifacts panel, image viewer tools, voice controls, settings rows of all 13 sections, onboarding steps, sheets, quick panel, palette) with its key path (e.g. `message.copy: [Tab to message, VO-Space or ⌘C]`, `version.next: ⌘]`). `KeyboardOnlyTests` executes each path with `typeKey`/`typeText` only (no `click`), asserting the expected effect via accessibility identifiers; every focused element shows `focus.ring` (snapshot assertion of the focus state in components' snapshot tests, test-strategy §4.3). Full Keyboard Access setting on: `defaults write -g AppleKeyboardUIMode -int 2` in the test VM/user **[perm: changes a global user default on the test machine; restore after: `defaults delete -g AppleKeyboardUIMode`]**.
5. Focus order: `FocusCoordinator` sets initial focus (composer on new chat; first field on sheets; primary button on alerts) and returns focus to the invoking control when sheets close.
