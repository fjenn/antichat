3. Public API (Sendable, async):
   ```swift
   public enum Verdict: Sendable { case allow, block }          // no reason, no score leaves the package
   public enum CheckError: Error, Sendable { case modelsMissing, modelsDamaged }
   public struct ModelManifest: Sendable { public let nsfw: URL; public let age: URL; public let nsfw2: URL?; public let sha256: [String: String] }
   public actor ChildSafetyCheck {
     public init(manifest: ModelManifest) throws(CheckError)   // verifies sha256 of every file; throws → caller shows safety.missing
     public func evaluate(image: CGImage) async -> Verdict
     public func evaluateVideo(frames: AsyncThrowingStream<VideoFrame, Error>, frameCount: Int, fps: Double) async -> Verdict
     public static func sampleIndices(frameCount: Int, fps: Double) -> [Int]   // ≥ 2 fps + first + last
   }
   public struct VideoFrame: Sendable { public let index: Int; public let image: CGImage; public let isPreview: Bool }
   ```
   Internal protocol `Detectors` (`nsfwScores(_:) async throws -> (pMedium: Float, pHigh: Float)`, `nsfw2Score(_:) async throws -> Float?`, `faces(_:) async throws -> [Rect+conf]`, `people(_:) async throws -> [Rect]`, `age(face:body:) async throws -> Float`, `bodyOnlyAge(body:) async throws -> Float`); production implementation lands in M4.T02; tests use `StubDetector` (test target only).
4. `DecisionRule` (model-matrix §10.3, exactly): `n = pMedium + pHigh`; `nude = n ≥ T_n || (nsfw2 ≥ T_n2)`; faces with conf ≥ 0.5 and side ≥ 24 px; match faces to people by IoU (`FaceBodyMatcher`, face box inside body box, highest IoU of the face-expanded box); `minor = any(age_face < 18 + m_face) || any(person without usable face: bodyOnlyAge < 18 + m_body) || (siglip2Installed && any(pChild + pTeen ≥ 0.5))` — the last clause is model-matrix §10.3's optional "child-likeness" signal (R-285 AC4); its detector method is added to `Detectors` only if the M4.T02 fallback installs SigLIP2, and `DecisionRuleTests` covers it with stub numbers either way; **block iff nude && minor**; adult content is never blocked. Short-circuit: if `!nude`, return `.allow` without running age (keeps latency low). **Fail closed:** any detector error or timeout (per-call timeout 2 s) **while nude or before nudity is known** → `.block`. `thresholds.json` = `{"T_n":0.35,"T_n2":0.50,"m_face":7,"m_body":12,"face_min_conf":0.5,"face_min_side_px":24,"timeout_ms":2000,"version":1}`; M4.T02 calibration may change values (version + 1), never the rule.
5. `VideoFrameSampler.sampleIndices`: every frame at a step of `max(1, floor(fps / 2))` (≥ 2 fps), plus index 0 and `frameCount − 1`, deduplicated and sorted; preview frames are always evaluated individually by the caller before display (`isPreview: true`). `evaluateVideo` blocks on the first blocked sampled frame (and stops consuming).
6. Tests (`$CSC`): `DecisionRuleTests` — truth table over (nude ∈ {no, T_n−ε, T_n, high}) × (faces: none, adult 40 y, 24 y, 26 y; bodies: none, body-only 29 y, 31 y) × (nsfw2 present/absent) using `StubDetector` numbers (not images); asserts adult NSFW (age ≥ 25 face, ≥ 30 body-only) → allow, SFW with any age → allow, nude + age_face 24 → block. `FaceBodyMatcherTests` (IoU table). `VideoFrameSamplerTests` (fps 8, 16, 24, 30; 1, 2, 81, 241 frames: indices include 0 and last; max gap ≤ fps/2 frames). `FailClosedTests` (nsfw error → block; age error while nude → block; age error while not nude → allow; timeout → block; init with a missing file → `modelsMissing`; wrong sha → `modelsDamaged`). `ManifestTests`.
7. `METHOD.md`: the calibration method (lawful proxies, detectors tuned separately, data never in the repo, metrics only), and a line `Legal sign-off: pending (K-060), required before M10` (R-285 AC7).
