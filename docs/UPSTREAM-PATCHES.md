# Edits to upstream (PocketPal) files

Every change AntiChat makes to a file that upstream owns. Each edit is marked `ANTICHAT:` in the file, kept as small as possible, and has one owner. `git merge upstream/main` should conflict only in these files. Rules: `docs/antichat/FORK.md`.

Integration lane = the agent that owns `package.json`, `yarn.lock`, `ios/Podfile*`, the Xcode project, Android Gradle files, `AndroidManifest.xml`, `metro.config.js`, `babel.config.js` and `patches/`.
